# React Learning Problems

This repository contains React learning problems completed through feature branches and merged into `develop`.

## Branch Structure

- `main`: README only.
- `develop`: complete React project after merging all feature branches.
- `feature/hello-world-app`: HelloWorld app setup.
- `feature/data-binding`: examples of React data binding.
- `feature/react-components`: reusable React components.
- `feature/routing-global-css`: routing and global CSS.
